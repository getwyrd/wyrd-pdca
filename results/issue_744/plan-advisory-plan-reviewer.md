- NEEDS-HUMAN — **The generation guarantee is impossible for the included tiny payloads.** `brief.md:31-36` requires changing seed/key/generation to change the bytes while also requiring exactly `size` bytes, including zero; `brief.md:128-129` relies on that distinction to detect stale reads. Every zero-byte generation is necessarily identical, and one-byte payloads have only 256 possible values, so arbitrary generations cannot remain distinct. The target gateway derives its ETag from the body (`crates/server/src/lib.rs:274-275`), which does not supply the missing distinction. Revise (B) to name representative non-empty test vectors and explicitly document the empty/tiny-payload limitation for the later oracle slice; do not promise universal same-size overwrite discrimination.

- NEEDS-HUMAN — **The required payload tests can pass without proving bounded streaming or direct range access.** The goal and design require independent ranges and bounded pieces (`brief.md:16-18,136-139`), but (A)–(C) only check hashes, differences, lengths and equality with slices of a whole payload (`brief.md:26-36`). A counter-mode generator that first materializes the entire object, or regenerates the prefix before returning a range, can satisfy those assertions. This also contradicts “Any keyed construction that meets (A)–(C) is acceptable” (`brief.md:139`). Add an explicit acceptance check for bounded retained state and computation starting at the requested block, with sparse reads near the 10 GiB class and reviewer evidence or a mutation check that rejects whole-object buffering/prefix traversal.

- NEEDS-HUMAN — **The size-class discriminator leaves the root-budget input unbound.** (D) varies chunk size and the explicit threshold, but never varies `--max-root-value-bytes` (`brief.md:37-43`); (E) checks flag resolution/echo and (F) checks defaults (`brief.md:44-54`). An implementation that records the supplied budget but always derives `T` using 50,000 can pass those specified size assertions. The tracker explicitly requires “Size classes are computed from the tuning parameters, not hardcoded” (`notes.json`, Definition of done), and the target capacity actually divides the root budget by the record width (`crates/core/src/multipart.rs:4940-4949`). Require a case changing only the root budget: at `C = 1 MiB`, a budget of 63,000 must move derived `T` from 158 MiB to 200 MiB, while fixed/C classes stay unchanged; also check that an explicit threshold still overrides that derivation. Require the hardcoded-root-budget mutant to fail.
