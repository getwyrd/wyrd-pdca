**The remaining implementation concern is a test-timeout gap.** The huge-size loop in `no_piece_exceeds_the_documented_bound_whatever_the_size` begins after its `bounded(...)` call has returned. A constructor that generates and skips the prefix therefore performs that work on the test thread with no deadline.

```rust
for block_index in 0..start / BLOCK_BYTES {

}
```
