Two builder-fixable concerns remain: valid recovery can be refused, and the envelope test does not measure the full transaction. These are advisory findings; the deterministic gate results retain their own authority.

- **P2 — Recovery rejects a valid history.** `prepare` expands every cursor before `resume_from` into hypothetical singleton batches (`crates/core/src/staged_publication.rs:474`). Purity of the hook does not make every hypothetical state an actual historical state. The independent probe uses one pure cursor-to-state function with states `[A, C, D, E, F, B]`. A fresh invocation commits all five segments in one A→B batch; its B→C flip is forced to return Conflict. Retrying the identical publication with `resume_from = 5` returns `FenceCycled { phase: Flip }` with zero commits, although the actual history is only A→B and C has never been held (`review-probes.log:5`). Make recovery validate actual/reconstructible fence history, or establish an explicit enforceable contract that makes reconstruction sound, while retaining refusal of real cycles. Add this coarse-batch recovery regression. The standalone reproducer is `pdca-reviewer-653-probes.rs:846`; rerun `./pdca-reviewer-653-probes reviewer_resume_after_one_coarse_batch_must_not_invent_prior_states --nocapture` from this directory.

- **P2 — The budget test omits precondition bytes.** The production budget includes every precondition's key and expected value (`crates/core/src/staged_publication.rs:666`), but the test's `mutation_bytes` helper counts only puts/deletes (`crates/core/tests/segmented_publication.rs:341`). The probe shows that its counter reports zero for a batch carrying 70,012 bytes of preconditions, so the 12,000-byte assertion can pass without establishing the whole-transaction property (`review-probes.log:3`). The independent targeted mutation run also leaves `key.len() + expected.len()` → multiplication alive (`review-mutant.log:3`). Count the complete transaction independently, and exercise a binding budget with substantial caller preconditions and durable-segment pins. This is a test defect, not evidence that the unmutated implementation currently exceeds its budget.
