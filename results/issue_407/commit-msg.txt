Add composable metadata nemesis: partition, clock skew, pause

The multi-node M4 metadata cluster could not be exercised under a reusable,
composable set of faults: the fault battery
(60469a49c9fdd6f3f6ea9f6077553940e651ddf9) hard-wires a one-shot partition
and a mid-commit kill into its own scenario, and no clock-skew fault class
existed anywhere in the tree. #408 needs to run the checked consistency
workload under real partition / clock-skew / process-pause faults behind a
seam it can import without reopening the fault lifecycle (ADR-0041: "nemesis
first, then the checked artifact").

wyrd-metadata-fault-conformance now owns a NemesisLeg lifecycle seam
(plan -> apply -> confirm materialized -> heal -> confirm healed) with typed
materialization evidence per leg, plus the three live-leg implementations:
an in-netns iptables DROP partition, a container-scoped libfaketime clock
skew (a static per-leg offset on ONE cluster node; the harness clock is
never touched, so recorded history order stays trustworthy), and a
freezer-cgroup docker pause. The legs are plain docker shell-outs with no
libfdb_c linkage, so the seam compiles unconditionally and is importable by
both the battery's tests and #408's server-side scenario.

The central drive_leg runner encloses the caller's workload in the fault and
enforces two rules on every exit path, including a panicking workload: a
fault that did not provably bite FAILS as inconclusive (never a silent
pass), and a heal that fails or is incomplete FAILS loudly (no leaked cut,
paused container, or skewed clock). The clock-skew leg additionally waits
for the cluster to fully recover and re-replicate after each forced
recreate, so it measures the skew, never the restart.

xtask gains only the leg enumeration, dispatch routing, and runner-argument
building (zero new dependencies), plus the opt-in runner
`WYRD_TIER1=1 cargo xtask metadata-nemesis`, which refuses a leg that ran
zero tests. The host-independent logic is exercised by two added suites
(xtask/tests/nemesis_orchestration.rs and
crates/metadata-fault-conformance/tests/nemesis_oracles.rs) inside the
unprivileged `cargo xtask ci`; the live legs run only against the
privileged deploy/fdb-multi-replica topology, off-ci.

Fixes #407
